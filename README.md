# Task Selection Input with Dropdown

This project is a simple task page that allows users to select a platform (like Facebook, Twitter, WhatsApp) from a dropdown menu and have the platform name displayed in an input field. It is built using **HTML**, **CSS**, and **JavaScript**.

---

## 🚀 Features

- **Dropdown Menu** for selecting a platform (Facebook, Twitter, WhatsApp)
- **Input field** that displays the selected platform name
- Simple and responsive design

---

## 🛠️ Technologies Used

- **HTML** – For structuring the content of the page
- **CSS** – For styling the page and dropdown
- **JavaScript** – To handle the dropdown selection and update the input field dynamically
